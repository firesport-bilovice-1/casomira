Časomíra pro požární sport – SDH Bílovice

Webové rozhraní vlastní časomíry pro požární sport, postavené na ESP32.

🌐 "OTEVŘÍT WEB ČASOMÍRY" (https://firesport-bilovice-1.github.io/casomira/)

Funkce

- Živé zobrazování časů koše, levého a pravého proudu
- Historie naměřených útoků
- Grafy a statistiky výkonů
- Výběr týmů a soutěžních drah
- Archiv tréninků
- Komunikace s externími LED displeji

Webová ukázka obsahuje uložená demonstrační data. Pro živé měření a ovládání je potřeba připojení k jednotce ESP32.

Projekt SDH Bílovice.
